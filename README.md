# SMK-512 Case

## Корпус для контроллера СМК-512 (плата rev 2.1)

![SMK-512 case](SMK-512%20case.jpg)
![SMK-512 case 2](SMK-512%20case%202.jpg)

Обе крышки печатаются наружной поверхностью к столику, толкатель — широким фланцем вниз. Поддержки не нужны.
Чтобы корпус лучше сочетался с БК, лучше печатать на текстурированном столике.

Для сборки понадобятся четыре самореза с потайной головкой **2.9x13** (DIN 7982) или **M3x12**. Их вкручивают снизу: через нижнюю крышку и отверстия платы в колонны верхней крышки.

Перед сборкой толкатель вставляют в шахту верхней крышки изнутри.

STL-модели корпуса:
- ***[SMK-512-Up.stl](SMK-512-Up.stl)*** - 3D-модель верхней крышки
- ***[SMK-512-Down.stl](SMK-512-Down.stl)*** - 3D-модель нижней крышки
- ***[SMK-512-Pusher.stl](SMK-512-Pusher.stl)*** - 3D-модель толкателя кнопки

Модели FreeCAD:
